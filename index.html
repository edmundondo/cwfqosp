This admin app needs a Supabase project to do anything useful — without one there's nothing to show (unlike cwfqosd, this app has no local-demo-mode fallback, since its whole point is cross-visitor analytics that local-only storage can't provide).

1. Create a free project at supabase.com.
2. Run schema.sql (in this repo) in its SQL Editor.
3. Copy the Project URL + anon public key into SUPABASE_CONFIG near the top of this file's <script> block — and into cwfqosd/index.html's too, so the two apps share data.
4. See README.md, "Bootstrapping your own admin account," for the last step.
